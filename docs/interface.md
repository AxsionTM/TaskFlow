# Интерфейс TaskFlow

## Принципы

- Тёмная космическая тема по умолчанию: глубокий navy-фон, стеклянные панели, неоновые акценты
- Один UI-код: внешний вид меняется только токенами темы
- SVG-иконки Lucide в едином outline-стиле, цвета наследуются от темы и приоритета

## Desktop

Сайдбар слева (навигация, проекты, тема, профиль), контентная область по центру, детальная панель задачи справа. Плотные таблицы в админке, канбан-колонки и матрица 2×2.

## Mobile (360–430px)

- Нижняя навигация: Сегодня, Фокус, центральная кнопка «+», Граф, «Ещё»
- Создание и детали задачи — bottom sheets с фиксированным футером
- Канбан — горизонтальный свайп колонок с индикатором, матрица — переключение квадрантов
- Без горизонтального скролла страницы; safe-area и клавиатура учтены

## Темы

| Тема | Фон |
|---|---|
| Light | Светлый воздушный |
| Dark | Ночной космос |
| Ocean | Неоновая глубина |
| Forest | Зелёные горы |
| Energy | Красное ядро |
| Neon | Фиолетовый киберпанк |
| Classic Black | Чистый чёрный без картинок и blur |

## Дизайн-система

Типографика Inter, радиусы 12–24px, чипы статусов, цветные dot-индикаторы приоритетов (красный/жёлтый/синий/зелёный), toast-уведомления, skeleton-заглушки, пустые и ошибочные состояния.
