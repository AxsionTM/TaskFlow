# Возможности TaskFlow

Актуальный список функций приложения.

## Задачи

- Создание, редактирование, удаление (корзина + восстановление)
- Статусы: к выполнению, в работе, выполнено
- Приоритеты, даты начала и окончания, время
- Подзадачи с чек-листом
- Теги, проекты, напоминания
- Режимы отображения: список, канбан, матрица Эйзенхауэра

## Повестка дня

Временная шкала дня с точностью до минут. Задачи раскладываются по времени начала, видны пересечения и свободные окна.

## Календарь

Месячная сетка, задачи по дням, дни рождения, drag-and-drop между днями, блок ближайших событий.

## Привычки и цели

- Привычки: ежедневные/еженедельные, стрики, отметки выполнения
- Цели: прогресс, дедлайны, связь с привычками

## Фокус

Pomodoro-таймер с пресетами, статистика сессий и минут, звуковое уведомление.

## Заметки

Одна большая заметка на задачу: создание из карточки задачи или вкладки «Заметки», превью в списке, автоудаление вместе с задачей.

## Дни рождения

Список с обратным отсчётом, напоминания, подсветка в календаре.

## Граф

Obsidian-style сеть задач и дней: физика узлов, поиск, zoom, статистика по дню и приоритетам, экспорт vault.

## AI Ассистент

Управление естественным языком на русском: создание и поиск задач, переносы сроков, подзадачи, заметки, итоги дня и недели, сводки. Работает в двух режимах: встроенный движок понимания и LLM через function calling (опционально). Опасные операции выполняются только после подтверждения в чате.

## Уведомления

Серверные уведомления: колокольчик с бейджем непрочитанного, dropdown-список, отметки прочитанного. Рассылка из админ-панели — всем или выбранным пользователям.

## Аутентификация

Регистрация с подтверждением email (6-значный код, TTL, cooldown), Cloudflare Turnstile, вход, восстановление пароля через код, OAuth (Google, GitHub). Блокировка аккаунта администратором.

## Админ-панель (`/admin`)

Dashboard, пользователи (просмотр, создание, переименование, баланс через транзакции, тарифы, роли, блокировка, удаление, смена пароля), задачи, уведомления и рассылки, Error Center, Audit Log, Feature Flags, Maintenance Mode, статус системы.

## Темы и устройства

Светлая, тёмная, Ocean, Forest, Energy, Neon, Classic Black. Desktop, планшет и мобильная версия с нижней навигацией и bottom sheets.
